### About Dataset
AVN Phishing Email Classification Dataset
Created by AVN BlueFox
Published under AVN Innovations

### AVN_Basic.csv:
This file contains 60,000 emails that have been cleaned and organized into a consistent structure. Each email includes:

subject,
sender,
receiver,
body text,
number of URLs found,
label

### Label meanings:
0 — Legitimate

1 — Phishing

2 — Garbage / intentionally added noise

The “garbage” class represents noisy or unusable messages that were included on purpose. It allows learners to practice tasks such as:

Data cleaning
Handling inconsistent labels

Filtering irrelevant samples

Building models that remain stable even when the dataset is imperfect

### Class Counts
Legitimate: 31,122

Phishing: 28,476

Garbage: 402
